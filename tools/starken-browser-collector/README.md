# MGP Starken Browser Collector

Colector local para obtener cotizaciones públicas desde el cotizador de Starken usando la conexión residencial del navegador.

- Primera corrida automática al instalar.
- Corridas programadas: martes y viernes a las 09:00 hora local.
- Cobertura inicial: Santiago Centro → 14 destinos, 5 perfiles de peso/dimensiones, domicilio y agencia.
- No contiene credenciales de Starken.
- La versión distribuida al usuario reemplaza `__COLLECTOR_TOKEN__` por un token MGP de alcance limitado solo a ingestión Starken.
